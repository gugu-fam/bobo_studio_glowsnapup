**署名検証手順**

目的: 本リポジトリで作成したローカル署名付きタグを他のローカル環境で検証する手順を示します。外部サービスを使わずローカルのみで完結します。

前提
- 公開鍵ファイル: `reports/public_gpg_079F1148E9F2C635.asc` がリポジトリに存在します。
- 対象タグ: `signed/audit-20260708T093006Z`（存在するタグ名は変動する可能性があります。`git tag --list` で確認してください）

手順

1) 公開鍵のインポート（検証側マシンで実行）

```bash
gpg --import public_gpg_079F1148E9F2C635.asc
gpg --list-keys --keyid-format=long
```

2) リポジトリのタグを取得（検証側マシン）

```bash
git fetch --tags origin
git tag --list
```

3) タグ署名の検証（検証側マシンで実行）

```bash
git tag -v signed/audit-20260708T093006Z
# 署名者情報、鍵ID、署名の有効性が表示されることを確認
```

4) 署名鍵の指紋を確認（追加チェック）

```bash
gpg --fingerprint 079F1148E9F2C635
```

補足
- 公開鍵ファイルを別メディアに退避して安全に保管してください。秘密鍵は絶対に公開しないでください。 
- ローカルでの署名検証は完全にオフラインで可能です。
- タグは検証用の監査記録です。タグを remote に push しない限りリモート側には表示されません。

トラブルシュート
- `git tag -v` で "Good signature" が出ない場合、公開鍵がインポートされていない、または別の鍵で署名されている可能性があります。公開鍵の指紋とタグ出力の鍵IDを照合してください。
