# KEY_ROTATION_CHECKLIST.md

## 目的
鍵ローテーション作業を安全かつ確実に実行するためのチェックリスト。

## 事前準備（必須）
- [ ] ローテーション作業日時を決定し関係者へ通知
- [ ] オフライン作業用マシンを準備（ネットワーク切断推奨）
- [ ] リボーク証明書のバックアップ場所を確認（オフライン）
- [ ] 現行鍵の指紋を記録しておく
- [ ] `reports/key_management/` に作業ログ用ディレクトリを作成

## ローテーション手順
1. オフラインマシンで新しいサブキーを生成
2. 新サブキーの指紋を記録
3. 新サブキーをエクスポート（秘密サブキーは暗号化して転送）
4. 受け取り側で秘密サブキーをインポート（受け取りログを保存）
5. テスト署名を行い検証
6. 必要なら既存配布物の再署名を実行
7. 公開鍵を更新して配布（`public_gpg_<KEYID>.asc`）
8. `reports/key_management/YYYYMMDD-rotate.log` を作成して全手順を記録

## 緊急リボーク手順
- [ ] リボーク証明書を即時インポートして鍵を失効
- [ ] 受け手へ失効通知を送付
- [ ] 新鍵を生成して上記ローテーション手順を実行

## 完了確認
- [ ] 新サブキーで署名したファイルが検証可能
- [ ] 旧サブキーの失効（必要時）を確認
- [ ] ログとバックアップを `reports/key_management/` に保存
